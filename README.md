## Tech stack

React 18, React Router, Framer Motion, Vercel

## Editing content

All text, links and project details live in `src/data/portfolioData.js`. The resume served by the "Download CV" button is `public/resume.pdf`.

## Run locally

```bash
git clone https://github.com/SachinGaikwad2204/my-portfolio.git
cd my-portfolio
npm install
npm start
```

Pushing to `main` redeploys the site on Vercel.
